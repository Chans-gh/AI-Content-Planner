## 0 为什么改

维护者请别人在自己的电脑上，用 DeepSeek Harness 和快速档模型装了本 Skill 和 ai-coding-video，从一句需求做完一支 89 秒的竖屏短视频（保险科普「前五年没有收益，为什么还要配置」，5 段 18 个分镜），并写了复盘。复盘的数我们重算过：口播不含标点 403 字，和说法一样长，实际语速 4.52 字/秒（复盘写的 469 字、5.26 字/秒算进了标点）；框架的篇幅合计 97 秒（复盘把 P3 读成 27 秒）。用 0.7.1 的 `check.py` 检查这两份策划文件，**通过**。下面这些问题，检查一条都没拦住：

1. **要念的话分散在八处，下游只执行其中一处。** 框架「要讲的点」和「怎么证明」、说法的「参考说法」和「不能丢的」、取舍、表达·边界、`content.md` 的「必须写清的」、待核实表，都在决定最后念什么；下游写逐字稿只认「参考说法」。取舍写着「分红、万能的不确定提示：保留，口播一句带过」「口播只留一句『以合同为准』」，说法里没有这两句，成片里也就没有。
2. **信息没有去向。** 11 条信息里有 3 条既没念也没上屏；其中 2.0% 是故意不讲（上屏像承诺收益），另外两条是漏了。从文件上分不出哪条是故意不讲、哪条是漏了。
3. **同一件事写了好几遍。** P1 换钩子以后，形式·注意力预算、效果自查、打法表、说法表头字数这四处都没跟着改；时长写了 97、100、90–105、110、约 90 五个版本。
4. **交接时还有没解决的事。** 待核实表 R1 写「已要求口播注明」，其实是推给了下游；P1 的原句「前五年，它都比交的钱少」撞上了 plan.md 自己的边界 ③（不把「前五年」写成全称），下游的规矩是原句不能改，就照念了。
5. **素材表常年空着。** 仓库里 9 份 `content.md`：受众表 9 份全空，素材表 5 份空（素材表只登记外部文件，纯代码画的片子没有外部文件）。代码画的片子真正的素材是上屏的数字、标签、小字、图表种类，这些现在散在信息、画面、约束三处。
6. **弱模型下游做不好样式。** 从效果、表达、立意推出每格用什么部件、什么字号，是一连串开放式判断；快速档模型做不稳。
7. **下游没有地方记偏离，就改了 plan.md。** 风格包里没有保单页部件，下游直接改了画面表的那一行，又在确认记录里加了一行；按 `handoff.md` 第 6 节，下游只能改缺口表和状态行。

所以这一版只做一件事：**把交接物收成一份 `content.md`**。下游照着做的东西只记在这里一处，交接前是闭合的（要念的都在「念什么」里，每条信息都有去向，没有没解决的冲突）；`plan.md` 只留给用户看，记的是决策和理由。

## 3 `content.md`（格式 5）

### 3.1 节的顺序

`总则`、`红线`、`约束`、每段一节（`## P1 段的作用`）、`素材`（可没有）、`资料清单`、`衍生`、`下游回报`。

**每段自足**：一段要念的、要看的、用到的信息都在这一节里，用到的约束、红线写编号；下游一次处理一段，不用在全文里跳着找。

### 3.2 头两行

```
# 内容：〔题目〕

格式：ai-content-planner/5
状态：〔效果待确认 | 框架待确认 | 补齐中 | 已交接 | 回流中〕（〔日期〕）。〔下一步一句〕
```

状态的取值和含义照旧，只是从 `plan.md` 挪到这里。`plan.md` 的第二行写 `格式和状态见 content.md`。

### 3.3 总则

表头 `项 | 内容 | 依据`，行固定、按这个顺序：

| 项 | 写什么 | 原来在 |
|---|---|---|
| 输出形式和规格 | 照旧 | 形式 |
| 篇幅 | 目标篇幅和可接受的区间（「90 秒，80–105」）；**全片只在这里写一次**，不写字数 | 形式·篇幅和注意力 |
| 注意力预算 | 前 N 秒 / 第 1 页之内完成什么，接触时刻一并写在这里 | 形式·篇幅和注意力、效果·接触时刻 |
| 结构 | 照旧 | 形式 |
| 声音 | 照旧 | 形式 |
| 证明方式 | 照旧 | 形式 |
| 制作条件 | 照旧（`能用：……；不能用：……`） | 形式 |
| 基调 | 照旧（14 档或「自定：」，可带局部档） | 表达 |
| 张力 | 照旧（1、2、3） | 表达 |
| 钩子 | 类型和方向；**句子不写在这里，写「见 S1」** | 表达 |
| 句式和节奏 | 照旧，写成能检查的样子 | 表达 |
| 情绪曲线 | 照旧；第 2 步排好段以后，每段的情绪标签照它填 | 表达 |

「依据」就是原来的「由哪条效果推出」和「来源」合在一格，给用户看，下游不用读。

### 3.4 红线（B）

表头 `# | 不许 | 怎么查 | 依据`，编号 `B1` 起。原来表达·边界里属于这个题自己的部分，一条一件事；`tone.md` 里所有基调都要守的底线照旧写在 `handoff.md`，不在这里重抄。

「怎么查」以下面三种之一开头：

- `词：` 后面跟「」引起来的词，下游并进禁用词检查。例：`词：「收益」「回报」「保本」；题目和钩子里引述客户原话除外`。
- `条件：` 一句「提到 X 时必须 Y」。例：`条件：提到分红型、万能型时，同一句说出「利益不确定」`。
- `人工：` 一句没法机检的。例：`人工：不把「前五年」讲成所有产品都这样；只在示例假设之后说`。

原来 `content.md`「必须写清的」里属于「不许这样讲」的，挪到这里（见 3.6「信息」）。

### 3.5 约束（K）

照旧。

### 3.6 每段一节

一段四块，按这个顺序。

**段头**：表头 `项 | 内容`，固定六行：

| 项 | 写什么 |
|---|---|
| 作用 | 本段任务，承接哪段（原框架「作用」） |
| 从 → 到 | 原框架「受众：从 → 到」 |
| 要讲的点 | `a. ……<br>b. ……`，照旧 |
| 篇幅 | 本段的秒数、页数或字数；**不写字数上限**，`check.py` 算 |
| 情绪 | 紧 / 松 / 稳 / 扬，后面可以跟「（段子手）」这类局部档 |
| 节奏 | 快 / 中 / 慢 |

情绪：**紧**是戳中、有点急；**松**是轻、有包袱；**稳**是踏实、给判断；**扬**是兴奋、往上走。节奏：**快**是短句、画面切得勤；**中**是一句一个画面；**慢**是画面停得久、留白多。下游照这两个标签和总则的张力查表定动效、每格时长、转场（SPEC-5-V），不再从情绪曲线自己推。

**念什么**：表头 `# | 点 | 句 | 级 | 依据`。

- `#`：`S1` 起，全片连续编，只增不改；删掉的号空着。
- `点`：这句讲本段的哪一点（`a`、`a、b`）。
- `句`：「」里是要念的话，一行一句（不超过 40 字）。PPT、报告、图文写标题句、论点句（`formats.md`）。
- `级`：
  - `原句`：字不改，只许改念法和断句。开头的钩子句（全片第一句）和终点动作那句一定是原句。
  - `必讲`：意思必须在，措辞可以压缩。
  - `可删①`、`可删②`……：时长不够时，下游按圈号从小到大删。
- `依据`：这句用到的信息编号（`P3-1`）、约束（`K2`）、红线（`B1`）；不说事实的写 `比喻`、`观点`、`过渡` 之一。说了事实、数字的句子必须写信息编号。

写的规矩（策划）：

- 有旁白的视频，每段字数上限 = 篇幅秒数 × 4.5。**原句 + 必讲**不超过上限的 85%；全部句子不超过上限的 115%。
- 每段至少一句「可删」；只有原句的段除外。可删的顺序是策划定的：先删的放小圈号。
- 每个要讲的点至少有一句「念什么」的 `点` 是它。
- 原来说法的「要的效果」不再单列：一段要的效果就是段头的「从 → 到」。原来「不能丢的」拆开写：原句写进级别；底线挪到红线；依据写进「依据」。
- 取舍里保留下来、要念的（「口播一句带过」），必须是一句「必讲」，并写进取舍的「落在」。

**看什么**：表头 `# | 要看到什么 | 来源 | 主角 | 最大的字 | 上屏的字 | 配哪句 | 用到`。

- `#`、`要看到什么`、`来源`、`用到`：照原画面表（`H1` 全片连续编；来源 8 个值；着落规矩照旧）。不再有「段」一列，所在的节就是段。
- `主角`：这一格画面的主角是哪一类，取下面 15 个之一，或写「其他：……」：

  | 主角 | 是什么 |
  |---|---|
  | 一个数 | 一个数字撑满一格 |
  | 两数对比 | 两个数并排比（前后、甲乙） |
  | 走势 | 一组数随时间变，常带一个交叉点或拐点 |
  | 构成 | 一个整体拆成几份 |
  | 排名 | 几项按大小排 |
  | 表格 | 行列都有意义，要逐格看 |
  | 流程 | 有先后的几步，或一条因果链 |
  | 清单 | 并列的几条，没有先后 |
  | 一句话 | 一句话就是画面（金句、结论、引语） |
  | 问答 | 一问一答 |
  | 地图 | 地点、路线、范围 |
  | 实物 | 产品、物件 |
  | 人 | 人物、角色 |
  | 场景 | 环境、事件现场 |
  | 界面 | 软件、网页、App 的画面 |

- `最大的字`：这一格字号最大的那几个字，照原文抄，一格只写一处（「第 8 年」）；主角是实物、人、场景、界面，画面本身就是重点的，写「无」。
- `上屏的字`：这一格上屏的数字、标签、小字，照原文写全（「1–10、20、30 年 12 个值；小字『示例 · 假设，非实际报价 · 2026-11』」）。纯代码画的片子，这一格就是它的素材。
- `配哪句`：这一格配着哪句念（`S3`），要是同一段的；不配某句的（片头、转场里承担证明的）写「无」。

主角、最大的字、上屏的字是内容上的决定（看什么、哪个最重要）；景别、构图、部件、字号归下游，照旧不写。

**信息**：表头 `# | 讲哪一点 | 内容 | 种类 | 来源 | 必须写清的 | 状态 | 去向`。前七列照旧，有两处变化：

- `必须写清的`只写**用这条信息时要带的口径**：单位、时间、版本、「示例 · 假设」这类标注。要说出来的话不写在这里，写成一句「念什么」（如「以合同现金价值表为准」）；不许怎么讲的，写成一条红线。
- 新加 `去向`，取下面几种，可以几种并列，用「；」隔开：
  - `念 S3` 或 `念 S1–S5`：哪几句念它；
  - `上屏 H3`：哪几格画面上屏它；
  - `依据`：只用来撑某句话，不念、不上屏，后面写撑的是哪句（`依据：S7`）；
  - `不讲：理由`：记着备查、成品里不用（替代原来「讲哪一点」写的「不用」）。

去向必须和「念什么」的依据、「看什么」的用到**两边对得上**：去向写 `念 S3` 的，S3 的依据要有这条；S3 的依据写了这条的，这条的去向要有 `念 S3`。

### 3.7 素材（M）

照旧的表头；只在有真实文件（用户给的图、视频，finder 找到的公开素材）时写这一节。纯代码画的片子不写这一节，素材就是每格的「上屏的字」。

### 3.8 资料清单

照旧，另外：

- 「位置」写本地路径的，路径要存在，相对项目根目录。
- 指到**别的** `plans/<短名>/` 的，拷进本目录的 `source/`，「位置」改写本目录的路径。别的策划目录清理了，这一份的证据链不能断。

### 3.9 衍生

原 `plan.md` 衍生，照旧。

### 3.10 下游回报

表头 `# | 段 | 类型 | 对象 | 说明 | 归谁 | 状态 | 怎么解决的`，交接时只有表头。下游加行，`X1` 起往后编。

| 列 | 取值 |
|---|---|
| 段 | 段号或「全部」 |
| 类型 | `删减`（删了可删的句）、`压缩`（压了必讲的措辞）、`偏离`（画面换了做法）、`缺内容`、`缺素材`、`冲突`（原句撞红线、两处要求对不上） |
| 对象 | `S3`、`H5`、`P2-2`、`B3` |
| 归谁 | `策划` / `下游` |
| 状态 | `待补` / `已补` / `已知悉` / `改内容关闭` |

## 4 `plan.md`（格式 5）

## 7 交接

`content.md` 状态改成「已交接」之前，全部满足（替代原来的 11 条，SKILL.md 照这里改写）：

1. 确认记录有「效果」「框架」两行（照旧）；
2. 缺口表没有归「策划」且「待补」的行（照旧）；
3. 待核实和有冲突表全部「已处理」，「落在」不空；
4. 每段每个要讲的点：至少一条信息的「讲哪一点」是它，至少一句「念什么」的「点」是它；
5. 用到的信息都是「已核实」或「设定」（照旧）；每条信息都有去向；去向和念什么的依据、看什么的用到两边对得上；
6. 要讲的点和信息写的是内容不是动作（照旧）；
7. 总则各行都写了，没有「待你定」；
8. 每段至少一行「看什么」，着落照旧；主角是 15 个之一或「其他：」；最大的字不空；
9. 有旁白的视频：全片第一句和终点那段有原句；每段的字数照第 3.6 节；

12. 下游回报只有表头，或者全部不是「待补」；
13. `check.py plans/<短名> --handoff` 通过。
