你在 ai-coding-video 仓库里干活。上游策划 Skill ai-content-planner 0.7.0 把交接格式升到 `ai-content-planner/4`；本 Skill 现在只认 `/3`、`/2`，要接上 `/4`。照本仓库 `AGENTS.md`：从最新 `main` 开分支；先在 `PLAN.md` 写成一个阶段（改哪些文件、每条新规则报错还是提醒），给维护者确认后再写代码。

### 格式 4 比格式 3 多了什么

1. 格式行是 `格式：ai-content-planner/4`。
2. **形式**：「声音」只写谁在说、对谁说、有没有旁白（口吻挪进了表达）。「制作条件」固定写成 `能用：……；不能用：……`（全角冒号、分号），用画面来源的名字，可以带括号里的限制，如「录像（只用 NASA 公开的）」。
3. **表达**（新节，在形式和立意之间），表头 `项 | 内容 | 由哪条效果推出 | 来源`，六项：
   - 基调：以下面 14 档之一开头，或写「自定：……」：冷静播报、讲透型、老友唠嗑、娓娓道来、悬念反转、走心共鸣、热血燃、犀利点评、段子手、直播间促单、权威专家、治愈陪伴、童趣、文艺诗意。可以带一段局部档（「讲透型；P5 换直播间促单」），括号里可能写着备选。
   - 张力：以 1、2、3 开头。1 克制：陈述句为主，不用感叹；2 有起伏：设问、对比、一两处感叹；3 强刺激：短句连发、反问、悬念。
   - 钩子：第一句用哪种钩子，那一句的方向。
   - 句式和节奏：写成能检查的样子，如「一句一个信息；全片不用感叹号」。
   - 情绪曲线：开头什么情绪 → 哪段到顶 → 收在什么情绪。
   - 边界：所有基调都守的底线（夸张只用在比喻、感受、节奏上，不用在事实、数字、功效上；不用极限词；不编证言；张力写进字里，不靠演绎），加这个题自己的；不能说的词一般用「」或『』引起来。
4. **画面**（新节，在框架和效果自查之间），表头 `# | 段 | 要看到什么 | 来源 | 用到`：
   - 每段至少一行；编号 `H1` 起，只增不改；一行一个段号。
   - 「要看到什么」只写内容，不写景别、运镜、构图，这些归下游。
   - 来源取 8 个值：代码画、照片、录像、录屏、数据、三维模型、生图、生视频。和 `data/tags.json` 的 `materials` 同名的（录像、录屏、照片、数据、三维模型、生图、生视频）意思一样；代码画就是 C 类。
   - 「用到」是编号，几条用「、」：信息 `P1-1`、说法的点 `P1 a`（中间有空格）、素材 `M1`、约束 `K1`、缺口 `Q1`。着落：代码画指到 `P1-1` 或 `P1 a`；照片、录像、录屏、三维模型指到 `M`，或归下游的 `Q`；数据指到 `P1-1` 或 `M`；生图、生视频至少一条 `K`，用到的 `M` 是能送生成的。
   - 只记承担证明或效果的画面；装饰、氛围、转场不记，下游自己定。
5. **说法**：表头不变。有旁白或上字的视频，说法按念的顺序排，合起来就是**口播初稿**，正本在策划。「参考说法」是这个点要念的话（「」里的字），可以是几句。「不能丢的」写了「原句」的那一行，字不改，只许把数字改成念法、断句；开头的钩子句和终点那句一定是原句。
6. 效果自查多了一行「表达」，下游不用读。

### 要改的（建议，命名和级别你们定）

1. `scripts/check_plan.py`
   - `FORMATS` 加 `/4`，`FORMAT` 改成 `/4`，仍认 `/3`、`/2`；`/1` 照旧停下。
   - 格式 4 读表达（六项都在、表头对）和画面（表头对、H 号不重复、段号在框架里、来源是 8 个值之一）。表头逐字比，读不出就报错，和现在读形式、说法一样。
   - **画面 → 分镜脚本**：每行 H 至少有一个分镜（或 `uses` 一条）认领。建议加一个可选字段，如 `view: "H1"`（几条写数组）。认领它的分镜类别要和来源对上：代码画 → C，照片、录像、录屏、数据、三维模型 → T，生图、生视频 → G；H 用到的 `M` 要出现在认领分镜的 `src`，用到的 `K` 要在它的 `rule` 里。没人认领的建议报错：交接的规矩是每行画面都要在成品里出现、来源照写，要换来源先回流。
   - **制作条件**：「不能用」里的来源，分镜里不能有对应的类别或素材类型（例：不能用生图、生视频 → 没有 G 类的画面分镜）。注意：策划的来源只管画面，「语音合成」不在其中；旁白怎么配照「声音」，不要因为「不能用：生图、生视频」就不让合成旁白。
   - **原句**：说法里「不能丢的」写了「原句」的行，取参考说法「」里的字，和逐字稿同 `seg` 的 `vo` 比：按 `show` 换成字幕写法、去掉标点和空格后，原句要在 `vo` 连起来的字里。数字的写法比不准，建议只提醒，同时在 `--table` 里把原句和 `vo` 并排打出来，给用户确认。
   - **表达**：张力是 1 的，`vo` 里有感叹号 → 提醒；边界里「」或『』引起来的词，并进 `tools/check_copy.py` 的禁用词（和项目的 `copy.json` 合并）。
   - 格式 3、2 的读法不变。
2. `storyboard.md`（接策划）
   - 开头和第 1 节改成格式 4；`/3` 也能接：没有表达、画面，照现在的读法，不查原句和画面认领。文末「格式 2」一节后面加「格式 3」和 4 的差别。
   - 第 2 节「读什么」：加表达、画面的读法；「制作条件」的新写法；说法是口播初稿、「原句」的意思。
   - 定样式（`film.md` 第 2 步）：每段先把画面行落成 `uses` 或分镜，主角类照画面的来源；画面表没写的自己定。
   - 第 3 节「怎么填引用」：H 的认领字段；`M` 进 `src`、`K` 进 `rule`（照旧）。
   - 第 4 节：逐字稿**从说法改**，不另起一份；改的只能是断句、念法、配合画面的增删；原句不动；照表达的基调、张力、句式和节奏写，边界一条不能破。合成音喊不出来、哭不出来，稿里不写「（激动地）」这类演绎提示。
   - 第 6 节「回流」：要换基调、张力，或改某行画面的来源（如生成改实拍）→ 缺口表加行，归策划，状态行改「回流中」。
3. `film.md`：有策划时，第 4 步「用户确认」多给两张对照：说法和逐字稿（原句标出来）、画面 H 和认领它的分镜。没有策划的流程不变。
4. 可选：一张基调 → 音色、语速、配乐的对照（冷静播报中速平稳、治愈陪伴慢、热血燃快……），归下游定，不回写策划。
5. `SKILL.md` 的描述和「接策划」那行写 `/4`（也认 `/3`、`/2`）；版本号加一档；CHANGELOG 一行；README 里提到 `/3` 的跟着改。
6. 测试：现在的 ok 夹具留作格式 3；新写一份格式 4 的 ok 夹具（有表达、画面、原句；画面里代码画、照片、生图各至少一行）；每条新规则至少一个测试。`cases/` 里两份格式 3 的 `plan.md` 不用转。
