## 取舍

| 内容 | 处理 | 理由 |
|---|---|---|
| 成分的作用（舒缓、修护、保湿之类） | 删除 | 要有功效评价依据（P6-3、P3-4），虚构商品没有；也不能借原料暗示功效（P3-5） |
| 「水润」标签 | 删除 | 听起来像保湿宣称；改成感官上的「水状」 |
| 适用肤质（干皮、油皮、敏感肌） | 延后 | 「适用敏感皮肤」是特定宣称（P6-4）；投流短片按人群分时只换场景和语气，不写适用肤质 |
| `case.json` 第 6 段的「INCI 成分表」 | 合并 | 国内标签用标准中文名称（P6-1），P6 按国内的讲；INCI 英文名不单讲 |
| FDA 的成分表规则（1% 以下任意排） | 删除 | 美国规则，国内是 0.1%（P6-2） |
| 「最」「第一」这类说法 | 删除 | 不需要，也免得碰广告用语的限制 |
