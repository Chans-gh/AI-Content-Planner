## 怎么回放的

- **输入**：每支案例 README 开头的场景描述（`news-artemis` 是「场景」一条，另外两支加上「商品」「规矩」或「这节课教什么」）。段落参考案例已定的 `case.json`。
- **按 Skill 走**：复制两份模板，阶段 1 写立意、段落、取舍、缺口，阶段 2 按缺口补，最后跑 `check.py --handoff`。
- **事实来源**：案例自带的 `script.json`、`case.json` 和里面的链接，2026-11-08 逐个重新下载、抽正文核对；案例没给来源的（护肤的法规、课件的短片题目），按 Skill 去找。读不到的照实写「没读成：原因」。
- **确认记录是模拟的**：回放里没有真的用户。用户的确认照案例 README、`case.json` 已定的写；案例没定、按 Skill 应该问用户的，按推荐项记，都标了「回放模拟」。
