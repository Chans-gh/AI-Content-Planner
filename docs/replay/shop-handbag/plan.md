## 取舍

| 内容 | 处理 | 理由 |
|---|---|---|
| 系列故事整段 | 合并进 P5 a，压到约 10 秒；旷野变成全片的画面底色 | 详情页的人要答案；氛围不需要一整段 |
| 超纤、亚克力、锌合金是什么 | 删除 | 买家不缺这几个定义；「珠子是亚克力」本身要讲，定义不讲；第 2 步就降成「不讲」，没派出去查 |
| 灰汁色、安可拉红、抹茶绿、蜜桃粉 | 保留，只展示包 | 没有模特图（M6），不编搭配 |
| 页面参数「适用场景：宴会」 | 删除 | 图都是草原日常，按图走 |
| 「已售 23」 | 删除 | 数字小，对犹豫的人是反作用 |
| 灵感来自某位摄影师的作品 | 删除 | 第三方的真名，进广告有风险（P5-5） |
