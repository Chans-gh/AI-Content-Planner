# 各题材交接时至少要有的

按内容类型找对应的一节（名字同 ai-coding-video 的内容类型）。每节三项：**常见段落组织**（只是起点，用户给了结构先沿用）、**交接前至少要有**（`plan.md` 段落表的「核心内容」和 `research.md` 里要能找到）、**不算数的写法**（只写了动作、没写内容，交接前要改掉）。

交接时按这里自查第 4 条「核心内容是具体内容」，在交接说明里写一句依据，例如：「三段的核心内容都写到了时间、主体和来源，没有只写『介绍』『分析』的」。

## 写全的三类

### 新闻资讯解说

- **常见段落组织**：发生了什么 → 为什么值得关注（背景）→ 细节和数字 → 各方怎么说 → 还不知道的、接下来看什么。
- **交接前至少要有**：
  - 核心事实：谁、做了什么、结果如何，一句一件事；
  - 时间：事情发生的时间和消息发布的时间，两个分开写；
  - 背景：观众要先知道的一两件事；
  - 来源和说法归属：哪句是官方公告、哪句是媒体报道、哪句是评论，分别标（种类 A、C 分开）；
  - 限制：还没确认的、数字的口径、说法不一的地方；事先公布的时间表、计划和事后的记录分开写；片里几个数字之间能算的（差值、合计）自己算一遍，对不上的按「有冲突」处理。
- **不算数的写法**：「介绍这条新闻，分析影响」「讲讲背景」「说说各方反应」。要写到「哪天发射、绕月几天、哪条官方公告说的」这一级，并引用对应的 U 编号。

### 产品广告和带货

- **常见段落组织**：痛点或场景 → 产品是什么 → 两三个卖点各带依据 → 怎么用、适合谁 → 价格和购买信息（有就写）。
- **交接前至少要有**：
  - 商品名和版本（型号、规格、颜色等会影响说法的）；
  - 每个卖点的依据：具体参数，或评测、实测的编号；品牌自述标「公司自己说的」（`C4`）；
  - 适用场景：谁、在什么情况下用；
  - 使用条件和限制：要配什么、什么情况下达不到宣传的效果、价格和活动的有效期。
- **不算数的写法**：「展示产品优势」「突出卖点」「讲讲性价比」。要写成「续航：官方称 30 小时（C4），关降噪时；第三方实测 26 小时（B5）」这样。
- 涉及广告用语限制（如「最」「第一」）的，查清平台规则和法规（`D1`、`D2`），写进取舍表。化妆品这类有功效宣称规定的品类，先查规定再写卖点：没有依据的功效（包括借原料暗示的）不写，只写看得见、摸得到的。

### 教程和录屏演示

企业培训和课件也按这一节。

- **常见段落组织**：做完能得到什么 → 准备（前提）→ 按顺序的步骤 → 怎么确认做对了 → 常见错和怎么办。
- **交接前至少要有**：
  - 前提：系统和版本、软件版本、要什么权限或账号、要先装好什么；
  - 先后步骤：每步一句，顺序就是操作顺序；
  - 每步的界面或控件名：菜单、按钮、输入框照界面上的字写，版本不同界面不同的写清是哪一版；
  - 成功标志：每步或最后一步做对了会看到什么；
  - 常见错：最容易出的一两个错、看到什么现象、怎么改。
- **不算数的写法**：「演示安装流程」「讲解基本操作」「介绍设置项」。要写成「设置 → 导出 → 把『分辨率』改成 1080p，看到右下角显示 1920×1080」这样。
- 缺录屏但还不知道点哪的，拆两行缺口：步骤归「策划」，录屏归「分镜后」。

## 其他题材

### 知识科普讲解

- 段落：提出问题 → 一步步讲清原理（`E1`、`E2`）→ 例子 → 收尾回答问题。至少要有：每个概念的大白话说法和出处、讲到哪一层为止。不算数：「讲解原理」「科普一下」。

### 品牌宣传片

- 段落：品牌是谁 → 做了什么 → 凭什么信 → 号召。至少要有：品牌事实（成立时间、做的事、代表案例）和出处，自述的标 `C4`。不算数：「展现品牌实力」「传递品牌温度」。

### 短剧 / 动漫剧 / 故事

- 段落：起 → 承 → 转 → 合，或按场次。至少要有：人物和关系的设定、每段发生了什么、转折在哪。不算数：「剧情推进」「制造冲突」。

### 音乐 MV

- 段落：按歌曲结构（前奏、主歌、副歌、桥段）。至少要有：每段对应的歌曲时间码、画面推进和素材。不算数：「配合音乐的画面」。

### 旅行和城市

- 段落：到哪 → 看什么 → 怎么去、花多少 → 小贴士。至少要有：地名、开放时间、价格、交通（易变的写查证日期）。不算数：「展示城市风光」。

### 年度回顾和数据总结

- 段落：总数 → 几个分项或时间点 → 亮点 → 展望。至少要有：每个数字的口径、统计时间范围、谁统计的（`B1`–`B3`、`G2`）。不算数：「回顾一年成绩」「展示数据」。

其余题材（口播 / 数字人、纪录片和纪实、体育赛事、儿童绘本动画、游戏和电竞、播客和访谈可视化、美食、健康和运动指导）按最接近的一节。

## 无旁白、纯情绪、虚构的片子

- 不强制写事实型口播：「核心内容」可以写每段的画面推进和情绪变化，「素材编排」写对应用哪份素材、还缺什么。
- 每段仍要具体：「镜头从空教室推到窗外的雨，结束在一把没拿走的伞」算数，「营造氛围」不算数。
- 虚构的人物、情节记成「设定」（见 `types.md` 第三节）。一旦出现真实地点、事件、产品能力，那一句照事实处理，照样核实。
