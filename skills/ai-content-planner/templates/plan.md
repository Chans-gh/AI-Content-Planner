# 内容策划：〔题目〕

格式：ai-content-planner/4
状态：〔效果待确认 | 框架待确认 | 补齐中 | 已交接 | 回流中〕（〔日期〕）。〔下一步一句〕

## 确认记录

- 〔日期〕效果：〔用户确认了什么；或「自动，未问用户（理由）」〕
- 〔日期〕框架：〔用户选了哪个打法、确认了什么；或「自动，未问用户（同上）」〕
- 〔日期〕局部：〔回到哪一步、哪几段、改了什么〕

## 需求

> 用户给的，原样记。

| 项 | 内容 | 来源 |
|---|---|---|
| 用途和场景 | 〔发在哪、给谁用、什么场合；以后还要怎么用〕 | 〔用户给的 / 材料里的 / 建议 / 待你定〕 |
| 必须有 | 〔用户点名要讲的；没有写「无」〕 | |
| 不要 | 〔禁区、不讲的；没有写「无」〕 | |
| 已有材料 | 〔用户给了什么、读到什么程度；详见 content.md 资料清单〕 | |
| 品牌与风格 | 〔有就写出处，具体怎么用留给下游；没有写「无」〕 | |

## 效果

> 从用户的每一句话里读出来；读不出的才问。写法见 `effect.md`。

| 项 | 内容 | 依据 | 来源 |
|---|---|---|---|
| 接触时刻 | 〔在哪、怎么遇到，当时在干嘛；主动看还是被推到眼前；能给多少注意力〕 | 〔读自需求哪一项、哪句；或「问来的」〕 | |
| 起点 | 〔谁；遇到时知道什么、信什么、感觉什么〕 | | |
| 阻力 | 〔① 受众心里的一句话<br>② ……（按强弱排）〕 | | |
| 终点 | 〔看完的状态 + 一个能看见的动作；不要动作的写明理由〕 | | |
| 衡量 | 〔用户怎么判断成没成；没有写「无」〕 | | |
| 杠杆 | 〔只有这个题有的：独有的事实、素材、身份、时机〕 | | |

## 表达

> 第 1 步写，和效果、形式一起给用户确认：给推荐，另给 1–2 个备选基调。档位和写法见 `tone.md`。

| 项 | 内容 | 由哪条效果推出 | 来源 |
|---|---|---|---|
| 基调 | 〔tone.md 的一档，或「自定：……」；要换档的段写「P5 换直播间促单」〕 | 〔接触时刻、阻力……〕 | |
| 张力 | 〔1 克制 / 2 有起伏 / 3 强刺激，加一句为什么〕 | | |
| 钩子 | 〔第一句用哪一种，写出那一句的方向〕 | | |
| 句式和节奏 | 〔挑几条，写成能检查的：一句一个信息；全片感叹号不超过 2 个〕 | | |
| 情绪曲线 | 〔开头什么情绪 → 哪段到顶 → 收在什么情绪〕 | | |
| 边界 | 〔tone.md 的底线之外，这个题自己的：合规条款、不能碰的说法〕 | | |

|---|---|---|---|---|---|
| A 〔名字〕 | 〔①〕 | 〔……〕 | 〔第一句或第一个画面〕 | 〔放弃了什么〕 | 〔选中的写「选」，其余空着〕 |

## 框架

内容流程：〔P1 → P2 → P3 的逻辑线，一句话〕

| 段 | 作用 | 受众：从 → 到 | 要讲的点 | 怎么证明 | 用到哪些输入 | 篇幅 |
|---|---|---|---|---|---|---|
| P1 | 〔本段任务，承接哪段〕 | 〔「受众心里原来的念头」→「看完这段的念头或动作」〕 | a. 〔一点一句〕<br>b. 〔……〕 | 〔用什么画面、演示、数据、证言让人信；用到的素材写 M、约束写 K〕 | 〔资料清单里的哪几份；没有写「无」〕 | 〔N 秒 / N 页 / N 字，或区间；不适用写「不限」〕 |

## 画面

> 第 2 步写，每段至少一行：要**看到**什么、从哪来。只记承担证明或效果的画面，装饰、氛围、转场归下游。来源只从形式「制作条件」的「能用」里挑。

| # | 段 | 要看到什么 | 来源 | 用到 |
|---|---|---|---|---|
| H1 | P1 | 〔画面的内容，不写景别、运镜〕 | 〔代码画 / 照片 / 录像 / 录屏 / 数据 / 三维模型 / 生图 / 生视频〕 | 〔代码画写 P1-1 或 P1 a；照片、录像、录屏、三维模型写 M 或归下游的 Q；数据写 P1-1 或 M；生图、生视频至少一条 K〕 |

## 说法

> 第 3 步写，每段至少一行，照表达写。有旁白或上字的视频，按念的顺序排，合起来就是**口播初稿**（每秒约 4 字，单句不超过 40 字）；开头的钩子句和终点动作那句在「不能丢的」写「原句」。下游可以按画面、时长改字、断句、调顺序；「原句」只改念法和断句；「要的效果」不能变，「不能丢的」一条不能少，不能加新的宣称。

| 点 | 要的效果 | 参考说法 | 不能丢的 |
|---|---|---|---|
| P1 a | 〔这个点要让受众怎样〕 | 〔「这个点要念的话，可以是几句」〕 | 〔原句；底线和依据：P1-1、K1、Q2；没有写「无」〕 |

## 衍生
