# 内容策划：〔题目〕

格式：ai-content-planner/3
状态：〔效果待确认 | 框架待确认 | 补齐中 | 已交接 | 回流中〕（〔日期〕）。〔下一步一句〕

## 确认记录

- 〔日期〕效果：〔用户确认了什么；或「自动，未问用户（理由）」〕
- 〔日期〕框架：〔用户选了哪个打法、确认了什么；或「自动，未问用户（同上）」〕
- 〔日期〕局部：〔回到哪一步、哪几段、改了什么〕

## 需求

> 用户给的，原样记。

| 项 | 内容 | 来源 |
|---|---|---|
| 用途和场景 | 〔发在哪、给谁用、什么场合；以后还要怎么用〕 | 〔用户给的 / 材料里的 / 建议 / 待你定〕 |
| 必须有 | 〔用户点名要讲的；没有写「无」〕 | |
| 不要 | 〔禁区、不讲的；没有写「无」〕 | |
| 已有材料 | 〔用户给了什么、读到什么程度；详见 content.md 资料清单〕 | |
| 品牌与风格 | 〔有就写出处，具体怎么用留给下游；没有写「无」〕 | |

## 效果

> 从用户的每一句话里读出来；读不出的才问。写法见 `effect.md`。

| 项 | 内容 | 依据 | 来源 |
|---|---|---|---|
| 接触时刻 | 〔在哪、怎么遇到，当时在干嘛；主动看还是被推到眼前；能给多少注意力〕 | 〔读自需求哪一项、哪句；或「问来的」〕 | |
| 起点 | 〔谁；遇到时知道什么、信什么、感觉什么〕 | | |
| 阻力 | 〔① 受众心里的一句话<br>② ……（按强弱排）〕 | | |
| 终点 | 〔看完的状态 + 一个能看见的动作；不要动作的写明理由〕 | | |
| 衡量 | 〔用户怎么判断成没成；没有写「无」〕 | | |
| 杠杆 | 〔只有这个题有的：独有的事实、素材、身份、时机〕 | | |

## 形式

| 项 | 内容 | 由哪条效果推出 | 来源 |
|---|---|---|---|
| 输出形式和规格 | 〔视频 / PPT / 课件 / 报告 / 图文 / 知识库；画幅或页面、语言等〕 | | |
| 篇幅和注意力 | 〔目标篇幅写最前面：60 秒、12 页、3000 字；再写注意力预算：前 N 秒 / 第 1 页 / 第一段之内完成什么〕 | 〔接触时刻〕 | |
| 结构 | 〔怎么组织，为什么〕 | | |
| 声音 | 〔谁在说、对谁说、什么口吻〕 | | |
| 证明方式 | 〔主要靠什么让人信或有感受：演示、实拍、数据、证言、故事、对比、参与……〕 | | |
| 制作条件 | 〔真人、实拍、生成、授权、预算的限制〕 | | |
| 衍生 | 〔拆条、别的平台、别的版本；没有写「无」〕 | | |

## 立意

一句话主线：〔……〕

| 打法 | 抓哪条阻力 | 用哪个杠杆 | 开头 | 代价 | 选 |
|---|---|---|---|---|---|
| A 〔名字〕 | 〔①〕 | 〔……〕 | 〔第一句或第一个画面〕 | 〔放弃了什么〕 | 〔选中的写「选」，其余空着〕 |

## 框架

内容流程：〔P1 → P2 → P3 的逻辑线，一句话〕

| 段 | 作用 | 受众：从 → 到 | 要讲的点 | 怎么证明 | 用到哪些输入 | 篇幅 |
|---|---|---|---|---|---|---|
| P1 | 〔本段任务，承接哪段〕 | 〔「受众心里原来的念头」→「看完这段的念头或动作」〕 | a. 〔一点一句〕<br>b. 〔……〕 | 〔用什么画面、演示、数据、证言让人信；用到的素材写 M、约束写 K〕 | 〔资料清单里的哪几份；没有写「无」〕 | 〔N 秒 / N 页 / N 字，或区间；不适用写「不限」〕 |

## 效果自查

| 查什么 | 结果 |
|---|---|
| 阻力 | 〔每条由哪段回应：① → P3；② → P5〕 |
| 终点 | 〔落在哪段：P6〕 |
| 注意力预算 | 〔预算之内完成了什么〕 |
| 换题测试 | 〔换成同类的题照样成立的段、不成立的段〕 |
| 衍生 | 〔从哪几段拿；形式的衍生是「无」写「无」〕 |

## 说法

> 第 3 步写，每段至少一行。下游可以改字、改节奏；「要的效果」不能变，「不能丢的」一条不能少，不能加新的宣称。

| 点 | 要的效果 | 参考说法 | 不能丢的 |
|---|---|---|---|
| P1 a | 〔这一句要让受众怎样〕 | 〔「……」〕 | 〔底线和依据：P1-1、K1、Q2；没有写「无」〕 |

## 衍生

> 形式的衍生是「无」时，这一节只写一行「无」，删掉下面的表。

| 条 | 用哪些点 | 第一句 | 放在哪 |
|---|---|---|---|
| D1 | 〔P1 a、P3 b〕 | 〔「……」〕 | 〔投流 15 秒、别的平台……〕 |
