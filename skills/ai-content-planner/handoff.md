# 交接说明（格式 5）

给下游 Skill（做视频、PPT、课件、报告等）看：策划交出来的是什么、怎么读、能改哪里。下游的用户不一定装了策划，所以这里写全，不靠别的文件。

## 1 文件

用户项目里的 `plans/<短名>/`：

| 文件 | 是什么 | 下游读不读 |
|---|---|---|
| `content.md` | **唯一交给下游的文件**：格式和状态、总则、红线、约束、每段一节（段头、念什么、看什么、信息）、素材、资料清单、衍生、下游回报 | 读，只读这一份 |
| `plan.md` | 给用户看的：确认记录、需求、效果、立意、效果自查、取舍、缺口、受众、待核实、检索记录 | 不用读 |
| `source/` | 原文（可能没有；私密的不进公开仓库） | 要核对出处时看 |

想先看一份精简版：`python3 -I <策划 Skill 目录>/scripts/brief.py plans/<短名>`，从 `content.md` 生成，末尾有每段的字数估算，不存档。没装策划的，直接读 `content.md`。

## 2 先认格式和状态

- `content.md` 第三行是 `格式：ai-content-planner/5`。版本号不认识，就停下，请用户更新下游或策划，不要猜着读。
- 下一行状态是「已交接」才接。「回流中」表示策划还在处理下游回报，等它改回「已交接」。

## 3 能用的编号

| 编号 | 是什么 | 写在哪 |
|---|---|---|
| `P1` | 段 | `content.md` 每段一节的标题 `## P1 ……` |
| `a`、`b` | 段里要讲的点 | 段头「要讲的点」（`a. ……<br>b. ……`）；别段引用写 `P1 a` |
| `S1` | 一句要念的话（全片连续编） | 每段的「念什么」 |
| `H1` | 一格画面（全片连续编） | 每段的「看什么」 |
| `P1-1` | 一条信息 | 每段的「信息」 |
| `B1` | 一条红线 | `content.md` 红线 |
| `K1` | 一条画面约束 | `content.md` 约束 |
| `M1` | 一张图、一段视频（或同类的一组） | `content.md` 素材 |
| `D1` | 一条衍生（拆条、别的版本） | `content.md` 衍生 |
| `X1` | 一条下游回报 | `content.md` 下游回报，下游加 |
| `Q1`、`V1` | 缺口、受众原话 | `plan.md`，下游不用 |

编号只增不改：删掉的号空着，不会被别的内容占用。

## 4 怎么读

- **总则**十三行管全片：输出形式和规格、篇幅（「90 秒，80–105」，全片只写这一处）、注意力预算、结构、声音、语速（慢 / 中 / 快 = 每秒 4 / 4.5 / 5 字，按念法数、不含标点，是整段含停顿的平均；对应配音倍速约 0.95 / 1.08 / 1.2，以真实配音为准，本地合成音约慢 13%；下游在下游回报或交付说明里报一句实测语速）、证明方式、制作条件（「能用：……；不能用：……」）、基调（一档写法，可带局部档）、张力（1 克制、2 有起伏、3 强刺激）、钩子（句子见 S1）、句式和节奏、情绪曲线。「依据」一列是给用户看的，下游不用读。视觉风格、配乐、剪辑归下游。
- **红线**一条一件事，「怎么查」三种：`词：` 后面「」里的词并进禁用词检查，例外写在「；除外：」后面，只认 S 编号和「题目」（`词：「收益」「回报」；除外：S1、题目`），写到的句子和题目不查这几个词，别的写法读不出就当没有例外；`条件：` 是「提到 X 时必须 Y」；`人工：` 要人看。所有基调都要守的底线：夸张只用在比喻、感受、节奏上，不用在事实、数字、功效上；极限词说事实的要有依据；张力写进字里，不靠演绎。
- **每段自足**，一次处理一段，按四块读：
  - **段头**：作用、从 → 到（这段把受众从哪个念头带到哪个念头）、要讲的点、篇幅、情绪（紧 / 松 / 稳 / 扬）、节奏（快 / 中 / 慢）。动效、每格时长、转场照情绪、节奏和总则的张力定。
  - **念什么**：按念的顺序排，合起来就是口播初稿。「级」：`原句` 字不改；`必讲` 意思必须在；`可删①②` 时长不够时按圈号从小到大删。「依据」是这句用到的信息、约束、红线，或「比喻」「观点」「过渡」。
  - **看什么**：要看到什么、来源（代码画、照片、录像、录屏、数据、三维模型、生图、生视频）、主角（一个数、两数对比、走势、构成、排名、表格、流程、清单、一句话、问答、地图、实物、人、场景、界面，或「其他：」）、最大的字（「无」表示画面本身是重点）、上屏的字（照写全，纯代码画的片子这就是素材）、配哪句（一格可以配几句：`S3、S4`、`S5–S7`，按列表读）、用到。景别、构图、字号归下游。
  - **信息**：讲哪一点、内容、种类、来源、必须写清的（用这条时要带的口径）、状态、去向。去向 `念 S3`、`上屏 H3` 是用在哪；`依据：S7` 只撑那句话，不念不上屏；`不讲：理由` 的下游也不要用。种类 `C4`（某方自己说的）不讲成第三方的事实，怎么讲照「必须写清的」：公司的数字讲成「官方称」，计划讲成「按计划」，用户（作者、品牌方）自己的观点讲成观点，不加「官方称」。
- **素材**一张一行：图上的字、标志、水印、人脸，能怎么用（原样、裁后用、重画、只作参考），能不能送进生成模型。
- **约束**是任何生成、重画、合成的画面都要守的样子。

## 5 冲突时谁让谁

从高到低，前面的赢：

| 级 | 是什么 | 能动到什么程度 |
|---|---|---|
| 1 | 红线 B、约束 K、第 4 节的底线 | 不能违反。原句撞红线时也不能照念：下游回报写一行「冲突」，回流 |
| 2 | 信息「必须写清的」口径 | 用到这条就要带上 |
| 3 | 原句 | 字不改，只改念法和断句 |
| 4 | 必讲 | 意思不丢，措辞可以压缩 |
| 5 | 篇幅 | 可以超出总则区间的 15% |
| 6 | 可删 ①②③ | 按圈号从小到大删 |

按这张表做的删减、压缩，记进下游回报（归「下游」，状态「已知悉」），不用回流；碰到 1、3、4 级要动的，回流。

## 6 下游的规矩和能改哪里

1. 从「念什么」改成稿，不另写一份；不能加新的宣称。每格「看什么」都要在成品里出现，来源照写；要换来源（如生成改实拍）、改结构、声音、证明方式、基调，先回流。看什么没写的下游自己定。
2. 生成、重画、合成的画面逐条对照 K，违反算返工；素材「能不能送生成」写「不能」的不进生成模型，写〔待核实〕的按「不能」处理；「只作参考」的不进成品。
3. 产物放在下游自己的目录（视频是 `videos/<短名>/`），不写进 `plans/`；写明来自哪份 `content.md`；引用段号写 `seg`（`"P1"`），事实写 `ref`（`"P1-1"`，设定写 `null`），约束写 `rule`（`"K1"`）；认领句子、画面建议写 `say`（`"S3"`）、`view`（`"H3"`），具体写法下游定。一段策划可以拆成下游的几段。

只许改 `content.md` 的两处，别的不改，也不改 `plan.md`：

1. **下游回报加行**：`#` 接着最大的 X 往后编；`段` 写段号或「全部」；`类型` 取 `删减`、`压缩`、`偏离`、`缺内容`、`缺素材`、`冲突`；`对象` 写 S、H、信息或 B 编号；`归谁` 写 `策划` 或 `下游`；`状态` 写 `待补`（等策划）或 `已知悉`（照第 5 节自己处理了）。只缺素材的归「下游」，补到了改成「已补」、写「怎么解决的」。
2. **状态行**：加了归「策划」且「待补」的行，就把状态改成「回流中」，请用户转给策划。

策划处理完会写「怎么解决的」、把状态改回「已交接」；下游按当时的 `content.md` 接着做，不恢复已删的内容。

## 7 格式升级

改节名、表头、取值、编号规则时，格式号加 1，策划的 CHANGELOG 写明怎么从旧格式转（1 → 2 见 0.4.0，2 → 3 见 0.6.0，3 → 4 见 0.7.0）。从格式 4 转格式 5（策划 0.8.0）：

1. `content.md` 头部加格式行 `/5` 和状态行（从 plan 挪来）；`plan.md` 第二行改成 `格式和状态见 content.md`，删掉状态行。
2. `content.md` 开头加总则：形式七项（衍生除外）和表达五项（边界除外）挪来，加一行语速（拿不准写 `中`），「依据」写原来的「由哪条效果推出」；「篇幅」去掉字数；「钩子」去掉句子，写「见 S1」。
3. 表达·边界拆成红线 `B1`…，一条一件事，补「怎么查」。
4. 每段一节前面加段头：作用、从 → 到、要讲的点、篇幅从框架挪来；情绪照情绪曲线填；节奏照基调和张力填。
5. 画面表按段拆进每段的「看什么」，补主角、最大的字、上屏的字、配哪句。
6. 说法按句拆进每段的「念什么」，S 全片连续编号：原句照旧；别的句子默认「必讲」，再定可删和顺序（每段至少一句，只有原句的段除外）；依据照原「不能丢的」写。每个要讲的点至少一句念它。
7. 信息加去向；原来「讲哪一点」写「不用」的，改成去向「不讲：理由」。原来「必须写清的」里要说出来的，补成一句「念什么」；不许的挪进红线。
8. 衍生挪进 content；末尾加下游回报（只有表头）。
9. 受众、待核实和有冲突、检索记录挪到 plan；待核实表补「状态」「落在」。
10. 取舍加「落在」一列：「保留」「合并」写 S、H、B、K 编号，「删除」「延后」写「无」。
11. `plan.md` 删掉形式、表达、框架、画面、说法、衍生。
12. 跑 `check.py --handoff`。
