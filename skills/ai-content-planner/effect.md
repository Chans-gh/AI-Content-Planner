# 效果和形式：怎么挖、怎么排、怎么交

`SKILL.md` 三步里和效果有关的写法都在这里；表达（怎么说）单独在 `tone.md`。不分类型：带货、获客、品牌、公益、预告、互动、课程、报告，都用同一套问法，区别只在答案。不要先认类型再套结构，从答案里推结构。

## 一、第 1 步：从用户的话里读出效果和形式

**逐句读**。用户说的每一句（用途、发在哪、给谁、多长、以后怎么用、给的材料），都问两遍：这句对**效果**意味着什么？对**形式**意味着什么？读出来的填进效果、形式两张表，「依据」写读自哪一句。例子：

| 用户说的 | 读出的效果 | 读出的形式 |
|---|---|---|
| 「放商品详情页」 | 看的人已经点进来、在犹豫；他要答案 | 最重要的答案放最前面；按问题分章，能拖着找 |
| 「发视频号，以后拆 15 秒投流」 | 刷到的人不认识你，3 秒内要停下 | 每段第一句单独能用；卖点排先后 |
| 「开场前放在大屏上」 | 观众在等、在分心 | 不靠旁白，靠画面和字；能循环 |
| 「领导要在周会上看」 | 他要拍板，没时间看细节 | 第 1 页就是结论和要他定的事 |

### 效果六问

| 项 | 写什么 | 不算数 | 算数 |
|---|---|---|---|
| 接触时刻 | 在哪、怎么遇到，当时在干嘛；主动看还是被推到眼前；能给多少注意力 | 「抖音用户」 | 「刷推荐流刷到，3 秒不抓住就划走」 |
| 起点 | 谁；遇到时知道什么、信什么、感觉什么 | 「年轻人」 | 「听说过这个病，觉得离自己很远」 |
| 阻力 | 什么让他不往终点走；按强弱排、编 ①②；每条写成**他心里的那句话** | 「信任度不足」 | 「① 这么贵，凭什么」「② 报了名也去不了」 |
| 终点 | 看完的状态，加一个**能看见的动作**；不要动作的写明「不要动作」和理由 | 「提升好感」 | 「点预约」「在评论区报出城市」「记住『X』这一个印象，下次能认出来」 |
| 衡量 | 用户怎么判断成没成；没有写「无」 | — | 「留资数」「到场人数」 |
| 杠杆 | 只有这个题有的东西：独有的事实、素材、身份、时机 | 「品质好」「用心」 | 「当事人自己来讲」「离开幕还有 7 天」「这款的盖子单手就能按开」 |

阻力和杠杆最要紧：阻力决定每段回应什么，杠杆决定差异从哪来。阻力先按推断写，标「推断」；有原话（评论、问答、客服记录、差评）就记进 `content.md` 受众，「依据」写 V 编号。

### 问什么

- 读得出的不问。读不出的才问，**最多 5 问，先问效果**：终点、阻力、接触时刻。
- 每问附一个默认答案，用户可以只回「按默认」。
- 生产问题（真人出镜、音色、画幅、预算）只在会改变效果时问；其余在形式表里写建议，用户确认效果时一起看。
- **用户就是当事方**（品牌方、主办方、作者、机构）时，阻力和受众原话直接问他：「大家最常问你什么？最常在哪一步放弃？」

### 形式：从效果推出来（`content.md` 总则的前八行）

| 项 | 怎么推 |
|---|---|
| 输出形式和规格 | 多半是用户给的 |
| 篇幅 | 目标和可接受的区间（「90 秒，80–105」）；全片只写这一处，不写字数 |
| 注意力预算 | 由接触时刻定：刷到的看前几秒，点进来的看前几十秒，会上看第 1 页，转发的看标题和首段 |
| 结构 | 由终点和阻力定：答案先给、分章、倒计时、先结论后展开、留给观众参与……写理由 |
| 声音 | 由起点和杠杆定：当事人第一人称、第三方讲解、不说话只上字；写清有没有旁白。口吻不写这里，写进表达 |
| 语速 | 有旁白的写 `慢`、`中`、`快`（每秒 4、4.5、5 字，按念法数、不含标点，整段含停顿的平均）；拿不准写 `中`；没有旁白写 `无` |
| 证明方式 | 由阻力定：怀疑「真的吗」靠演示、实拍、数据、证言；觉得「跟我无关」靠一个具体的人或场景；「懒得动」靠简单到看一眼就能做 |
| 制作条件 | 写成「能用：……；不能用：……」，用画面来源的名字（代码画、照片、录像、录屏、数据、三维模型、生图、生视频），限制写在名字后的括号里（「生图（只出手）」「录像（只用 NASA 公开的）」），括号里可以有逗号；真人、实拍、授权、预算的限制都落进这两句 |

用户说的以后怎么用（衍生）写进 `content.md` 衍生，没有写「无」。形式定了，再从效果推出**表达**（总则后五行：基调、张力、钩子、句式和节奏、情绪曲线）和**红线**，和效果、形式一起给用户确认，写法和档位见 `tone.md`。

## 二、第 2 步：打法、框架、效果自查

**打法**给 2–3 个。区别必须在于**抓哪条阻力、用哪个杠杆**；只是同一句话换个说法的不算两个打法。每个写开头（第一句或第一个画面）和代价（放弃了什么），标一个推荐和理由。用户给了结构的，打法可以只有一个。

**框架**写进 `content.md` 每段的段头（作用、从 → 到、要讲的点、篇幅、情绪、节奏）：

- **受众：从 → 到**：「原来的念头」→「看完这段的念头或动作」。「到」不写「知道 X」，写他心里变成了什么，或者做了什么。教程这类以学会为目的的，写「能做到 X」。
- **情绪**（紧 / 松 / 稳 / 扬）和**节奏**（快 / 中 / 慢）：照总则的情绪曲线逐段填。紧是戳中、有点急；松是轻、有包袱；稳是踏实、给判断；扬是兴奋、往上走。快是短句、画面切得勤；中是一句一个画面；慢是画面停得久、留白多。
- 用什么让人信或有感受，写成这段的「看什么」：用到的素材写 M，要守的写 K。

排段时守四条：注意力预算之内完成第一个「从 → 到」；每条阻力都有段回应；杠杆放在最先、最容易被记住的位置；终点的动作有一段落下来。

**缺口排先后**：受众证据（阻力是不是真的）→ 杠杆事实（独有的那一点站不站得住）→ 支撑事实 → 原理定义。只为讲清原理才要查的，先问它推动哪个念头；推不动就降成「不讲」或一句带过，不派出去查。

**效果自查**六项：

| 项 | 写什么 |
|---|---|
| 阻力 | 每条由哪段回应：「① → P3；② → P5」 |
| 终点 | 动作落在哪段 |
| 注意力预算 | 预算之内完成了什么 |
| 换题测试 | 把题换成同类的另一个（另一款商品、另一场活动、另一个机构），哪些段照样成立、哪些不成立。开头和收口都还成立，说明没用上杠杆 |
| 表达 | 钩子是哪一种、`S1` 在不在注意力预算之内（字数看 `brief.py`，不手写字数、秒数，也不抄句子）；张力档和全片的感叹、反问个数对不对得上；红线逐条查过 |
| 衍生 | 从哪几段拿；没有写「无」 |

## 三、第 3 步：看什么、念什么、去向、受众、素材、约束、衍生

**看什么**（每段一张，`H1` 起全片连续编）：第 2 步写每格要**看到**什么、从哪来，第 3 步补着落。只记承担证明或效果的画面：杠杆所在的、念什么要配的；装饰、氛围、转场不记，归下游。「要看到什么」写内容，不写景别、运镜、构图：「两条距离并排比长短：40 万 7 千公里和阿波罗 13 号」「手把 5 样东西依次放进包里」。来源只从制作条件「能用」里挑，「用到」按来源写够：

| 来源 | 是什么 | 「用到」必须有 |
|---|---|---|
| 代码画 | 数据图、示意图、文字卡、标注、动效，全部由程序画出来 | 画的信息 `P1-1`，或上屏的点 `P1 a` |
| 照片、录像、三维模型 | 真实拍的照片、扫描件、官方图、截图；实拍视频；网格、贴图 | `M`，或归下游的 `Q`（写清拍什么、谁来拍） |
| 录屏 | 软件、网页的屏幕录像 | `M`，或 `Q`；步骤先在信息里写清（步骤归策划，录屏归下游） |
| 数据 | 表格、地图、卫星图这类要用真实数据画的 | 数据本身的 `P1-1`，或数据文件的 `M` |
| 生图、生视频 | 图像、视频模型生成 | 至少一条 `K`；参照的 `M` 要「能送生成」 |

- **主角**：这一格的主角是哪一类，15 个取一个，或写「其他：……」：一个数、两数对比、走势（一组数随时间变）、构成（整体拆几份）、排名、表格（要逐格看）、流程（有先后，或因果链）、清单（并列没有先后）、一句话（金句、结论、引语）、问答、地图、实物、人、场景、界面。
- **最大的字**：这一格字号最大的那几个字，照原文抄，只写一处（「第 8 年」「252,756」）；主角是实物、人、场景、界面，画面本身是重点的写「无」。它要出现在上屏的字或配的那句里。**上屏的字**：上屏的数字、标签、小字照写全（「1–10、20、30 年 12 个值；小字『示例 · 假设，非实际报价』」）；纯代码画的片子这就是素材。**配哪句**：同一段的 S，几句写「S3、S4」或「S3–S5」；不配某句的写「无」。景别、构图、字号归下游。
- 真实的人、产品、地点、事件，要「是它本身」才有说服力的，写照片、录像，不写生图；生成只用在示意、想象、氛围，或用户确认可以生成的产品画面（守 K）。真人的脸、真人的声音不用生成。
- 照片、录像先派 finder 找官方新闻稿和媒体资源页、公共领域和 CC0 的图库，找到记 M（链接、许可原文、查证日期），找不到进缺口归下游。素材表里的 M 都要被某格用到。

**念什么**（每段一张，`S1` 起全片连续编），照总则写，写给下游看：

- **定性**：一行一句（不超过 40 字），按念的顺序排；有旁白或上字的成品，合起来就是**口播初稿**，正本在策划。PPT、报告、文章写标题句、论点句（`formats.md`「念什么写到多细」）。
- **点**：这句讲本段哪一点；每个要讲的点至少一句。**依据**：用到的信息、约束、红线编号；不说事实的写「比喻」「观点」「过渡」之一；说了数字、事实的必须有信息编号。
- **级**：`原句` 字不改，只许改念法和断句，全片第一句（钩子）和终点动作那句一定是原句；原句里有「今天」「刚刚」这类时间词的，红线写明哪天前发。`必讲` 意思必须在，措辞可以压缩。`可删①`、`可删②`…… 时长不够时下游按圈号从小到大删：先删的放小圈号，通常是例子、过渡、重复强调。每段至少一句可删，只有原句的段除外。
- **字数**：有旁白的视频，每段上限 = 篇幅秒数 × 语速档（总则「语速」）；字按念法数，数字照念出来的算（「2.0%」念「百分之二点零」算 6 字，年份一位一位念），语速档已经含句间、段首段尾的停顿，不另扣；原句 + 必讲不超过上限的 85%，全部不超过 115%。这是估算，超了 `check.py` 只提示、`brief.py` 打出每段的数；时长以下游配音实测为准，超了下游照 `handoff.md` 第 5 节删。段的篇幅反过来也照字数分，别一段松一段紧。
- 取舍里保留下来、要念的（「口播一句带过」），写成一句必讲，取舍的「落在」写它的 S。

**去向**（信息表最后一列）：每条信息都写，可以几种并列，用「；」隔开：`念 S3`、`念 S1–S5`；`上屏 H3`；`依据：S7`（只撑那句话，不念不上屏）；`不讲：理由`（记着备查、成品里不用，有冲突没用上的也写这个）。去向要和念什么的依据、看什么的用到两边对得上。「必须写清的」只写用这条时要带的口径；要说出来的话写成一句念什么，不许怎么讲的写成红线。

**受众**（`plan.md`，V）：评论区、问答、客服记录、差评、后台数据。照录原话，写平台、时间、条数、是不是挑出来的；它只代表说话的那部分人。公开的可以派 finder 找；要登录的请用户导出。

**素材**（M）逐张看，一张一行（同一类、处理一样的可以一组一行，写清张数）：

- 画了什么、拍了什么；图上的字、标志（包括别家的）、水印、人脸，逐项写；
- 能怎么用：原样 / 裁后用（裁哪里）/ 重画（为什么）/ 只作参考；
- 能不能送生成：有真人的脸、别家的标志、授权不清的，写「不能」或〔待核实〕。

**约束**（K）：生成、重画、合成任何画面都要守的样子，一条一件事。

- 产品的结构和外观：部件在哪、怎么连、什么颜色、有几个；**看不到的写「看不到，不要画」**；
- 人物、场所、界面：真人长什么样不进生成、界面以哪个版本为准；
- 抽象意象（「露珠」「未来感」「烟火气」）：给具体参照，指到 M；材料里没有参照的，写「下游定」，不替它编一个具体的东西。

**衍生**：每条写用哪些点、第一句、放在哪。第一句要单独能用，不靠前文。

## 四、自查一遍

- 效果表里有没有「引发共鸣」「提升好感」「增强信任」这类话？改成念头或动作。
- 框架的「到」是不是都是「知道 X」？是的话，这份还是说明书。
- 换题测试：开头一段换了题还成立吗？成立就是没用上杠杆。
- 下游只读 `content.md`，能不能做出这个效果？不能的话，缺的东西补进念什么、看什么。
- 下游只读看什么，能不能开分镜，不用回来问「这段画什么、图从哪来、哪个字最大」？不能的话，补格子或着落。
