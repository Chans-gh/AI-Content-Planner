# 效果和形式：怎么挖、怎么排、怎么交

`SKILL.md` 三步里和效果有关的写法都在这里。不分类型：带货、获客、品牌、公益、预告、互动、课程、报告，都用同一套问法，区别只在答案。不要先认类型再套结构，从答案里推结构。

## 一、第 1 步：从用户的话里读出效果和形式

**逐句读**。用户说的每一句（用途、发在哪、给谁、多长、以后怎么用、给的材料），都问两遍：这句对**效果**意味着什么？对**形式**意味着什么？读出来的填进效果、形式两张表，「依据」写读自哪一句。例子：

| 用户说的 | 读出的效果 | 读出的形式 |
|---|---|---|
| 「放商品详情页」 | 看的人已经点进来、在犹豫；他要答案 | 最重要的答案放最前面；按问题分章，能拖着找 |
| 「发视频号，以后拆 15 秒投流」 | 刷到的人不认识你，3 秒内要停下 | 每段第一句单独能用；卖点排先后 |
| 「开场前放在大屏上」 | 观众在等、在分心 | 不靠旁白，靠画面和字；能循环 |
| 「领导要在周会上看」 | 他要拍板，没时间看细节 | 第 1 页就是结论和要他定的事 |

### 效果六问

| 项 | 写什么 | 不算数 | 算数 |
|---|---|---|---|
| 接触时刻 | 在哪、怎么遇到，当时在干嘛；主动看还是被推到眼前；能给多少注意力 | 「抖音用户」 | 「刷推荐流刷到，3 秒不抓住就划走」 |
| 起点 | 谁；遇到时知道什么、信什么、感觉什么 | 「年轻人」 | 「听说过这个病，觉得离自己很远」 |
| 阻力 | 什么让他不往终点走；按强弱排、编 ①②；每条写成**他心里的那句话** | 「信任度不足」 | 「① 这么贵，凭什么」「② 报了名也去不了」 |
| 终点 | 看完的状态，加一个**能看见的动作**；不要动作的写明「不要动作」和理由 | 「提升好感」 | 「点预约」「在评论区报出城市」「记住『X』这一个印象，下次能认出来」 |
| 衡量 | 用户怎么判断成没成；没有写「无」 | — | 「留资数」「到场人数」 |
| 杠杆 | 只有这个题有的东西：独有的事实、素材、身份、时机 | 「品质好」「用心」 | 「当事人自己来讲」「离开幕还有 7 天」「这款的盖子单手就能按开」 |

阻力和杠杆最要紧：阻力决定每段回应什么，杠杆决定差异从哪来。阻力先按推断写，标「推断」；有原话（评论、问答、客服记录、差评）就记进 `content.md` 受众，「依据」写 V 编号。

### 问什么

- 读得出的不问。读不出的才问，**最多 5 问，先问效果**：终点、阻力、接触时刻。
- 每问附一个默认答案，用户可以只回「按默认」。
- 生产问题（真人出镜、音色、画幅、预算）只在会改变效果时问；其余在形式表里写建议，用户确认效果时一起看。
- **用户就是当事方**（品牌方、主办方、作者、机构）时，阻力和受众原话直接问他：「大家最常问你什么？最常在哪一步放弃？」

### 形式七项：从效果推出来

| 项 | 怎么推 |
|---|---|
| 输出形式和规格 | 多半是用户给的 |
| 篇幅和注意力 | 目标篇幅写最前面；注意力预算由接触时刻定：刷到的看前几秒，点进来的看前几十秒，会上看第 1 页，转发的看标题和首段 |
| 结构 | 由终点和阻力定：答案先给、分章、倒计时、先结论后展开、留给观众参与……写理由 |
| 声音 | 由起点和杠杆定：当事人第一人称、第三方讲解、不说话只上字 |
| 证明方式 | 由阻力定：怀疑「真的吗」靠演示、实拍、数据、证言；觉得「跟我无关」靠一个具体的人或场景；「懒得动」靠简单到看一眼就能做 |
| 制作条件 | 能用和不能用的：真人、实拍、生成、授权、预算 |
| 衍生 | 用户说的以后怎么用；没有写「无」 |

## 二、第 2 步：打法、框架、效果自查

**打法**给 2–3 个。区别必须在于**抓哪条阻力、用哪个杠杆**；只是同一句话换个说法的不算两个打法。每个写开头（第一句或第一个画面）和代价（放弃了什么），标一个推荐和理由。用户给了结构的，打法可以只有一个。

**框架**每段写：

- **受众：从 → 到**：「原来的念头」→「看完这段的念头或动作」。「到」不写「知道 X」，写他心里变成了什么，或者做了什么。教程这类以学会为目的的，写「能做到 X」。
- **怎么证明**：用什么让人信或有感受；用到的素材写 M，要守的写 K。

排段时守四条：注意力预算之内完成第一个「从 → 到」；每条阻力都有段回应；杠杆放在最先、最容易被记住的位置；终点的动作有一段落下来。

**缺口排先后**：受众证据（阻力是不是真的）→ 杠杆事实（独有的那一点站不站得住）→ 支撑事实 → 原理定义。只为讲清原理才要查的，先问它推动哪个念头；推不动就降成「不讲」或一句带过，不派出去查。

**效果自查**五项：

| 项 | 写什么 |
|---|---|
| 阻力 | 每条由哪段回应：「① → P3；② → P5」 |
| 终点 | 动作落在哪段 |
| 注意力预算 | 预算之内完成了什么 |
| 换题测试 | 把题换成同类的另一个（另一款商品、另一场活动、另一个机构），哪些段照样成立、哪些不成立。开头和收口都还成立，说明没用上杠杆 |
| 衍生 | 从哪几段拿；没有写「无」 |

## 三、第 3 步：说法、受众、素材、约束、衍生

**说法**每段至少一行，写给下游看：

- **要的效果**：这一句要让受众怎样，用框架的「到」的口吻。
- **参考说法**：一句就够，照形式的声音写。它是方向，不是定稿；但事实、数字、口吻要能直接用。
- **不能丢的**：底线和依据，写编号：没核实的不能说（Q）、要带的限定（「官方称」「手工测量」）、合规（写依据那条规定的编号，如 P2-3）、画面要守的（K）、不能用的素材（M）。没有写「无」。

**受众**（V）：评论区、问答、客服记录、差评、后台数据。照录原话，写平台、时间、条数、是不是挑出来的；它只代表说话的那部分人。公开的可以派 finder 找；要登录的请用户导出。

**素材**（M）逐张看，一张一行（同一类、处理一样的可以一组一行，写清张数）：

- 画了什么、拍了什么；图上的字、标志（包括别家的）、水印、人脸，逐项写；
- 能怎么用：原样 / 裁后用（裁哪里）/ 重画（为什么）/ 只作参考；
- 能不能送生成：有真人的脸、别家的标志、授权不清的，写「不能」或〔待核实〕。

**约束**（K）：生成、重画、合成任何画面都要守的样子，一条一件事。

- 产品的结构和外观：部件在哪、怎么连、什么颜色、有几个；**看不到的写「看不到，不要画」**；
- 人物、场所、界面：真人长什么样不进生成、界面以哪个版本为准；
- 抽象意象（「露珠」「未来感」「烟火气」）：给具体参照，指到 M；材料里没有参照的，写「下游定」，不替它编一个具体的东西。

**衍生**：每条写用哪些点、第一句、放在哪。第一句要单独能用，不靠前文。

## 四、自查一遍

- 效果表里有没有「引发共鸣」「提升好感」「增强信任」这类话？改成念头或动作。
- 框架的「到」是不是都是「知道 X」？是的话，这份还是说明书。
- 换题测试：开头一段换了题还成立吗？成立就是没用上杠杆。
- 下游只读说法、约束、框架，能不能做出这个效果？不能的话，缺的东西补进说法。
