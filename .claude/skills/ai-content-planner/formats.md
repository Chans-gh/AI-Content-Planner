# 各输出形式

需求的「输出形式」定了以后看这张表：篇幅写什么单位、交给谁。

| 输出形式 | 篇幅单位 | 交给谁 |
|---|---|---|
| 视频 | 秒 | [ai-coding-video](https://github.com/Chans-gh/AI-Coding-Video)（`storyboard.md`） |
| PPT | 页 | 做幻灯片的 Skill 或人 |
| 课件 | 页或分钟 | 做课件的 Skill 或人 |
| 报告 | 字 | 写报告的 Skill 或人 |
| 图文 | 字 | 写图文的 Skill 或人 |
| 知识库 | 不限 | 建知识库的工具或人 |

段怎么切、交接前多查什么，按题材和输出形式自己判断；通用的两条底线（不算数的写法、合规先查）见 `SKILL.md`「规矩」。

篇幅写法（`check.py` 认的）：「45 秒」「40–50 秒」「1 分 30 秒」「3 页」「1500 字」「3 千字」「不限」；各段合计和需求的目标篇幅差超过 15% 会提示。
